# 応用情報技術者試験・学習マスター

ChatGPT の「応用情報試験」プロジェクト用の **唯一の正本 (Single Source of Truth)** を、このリポジトリで管理します。

## ファイル構成

- **[`master.json`](./master.json)** — 唯一の学習データ正本。160問、160論点、既存履歴、追記式の演習ログを格納
- **[`index.html`](./index.html)** — 学習進捗を閲覧するための静的HTML（データは `master.json` から取得）

Excel / Google Sheets / 別ファイルの差分台帳は今後の正本にしません。Git の履歴によって過去版を追跡します。

> **公開範囲について**: このリポジトリは Public です。問題と学習履歴は第三者に閲覧され得ます。非公開で運用したい場合はリポジトリの Visibility を Private に変更し、GitHub Pages の公開にも注意してください。

## データの見方

`master.json` には以下のフィールドがあります。

| フィールド | 用途 |
| --- | --- |
| `questions` | 問題ID、問題文、採点ポイント、出題進捗 |
| `topics` | 論点ID、L1～L4、別日確認、復習優先度、習得判定 |
| `attempts` | 演習イベントの追記ログ。実際の回答、採点、根拠、類題区分 |
| `reference` | 移行元の過去の学習履歴、運用ルール、照合記録、元の進捗集計 |
| `source` | 初回Excelからの移行情報と最終更新セッション |

元の問題ID・論点IDと、過去の実測／推定履歴を保持します。正本に含まれる「初期進捗サマリー」は **移行時点の記録** であり、現在の進捗は `questions`・`topics`・`attempts` から算出してください。

2026-10-25に移行元の9シートを1回だけ取り込み、次のコミットで同日の18演習イベントを追記しました。**初期状態を含む履歴はGitのコミット履歴から確認可能**です。

## ChatGPTプロジェクトの運用指示（貼付け用）

```text
応用情報技術者試験・科目Aの学習データの唯一の正本は、GitHub の kawauso29/ap リポジトリ main ブランチの master.json である。
https://github.com/kawauso29/ap/blob/main/master.json

出題前に GitHub 連携で最新 master.json を読み、questions・topics・attempts のうち必要な範囲で出題対象、理解レベル、復習優先度を判断する。
過去のチャットやExcel、プロジェクト添付ファイルは正本の代わりにしない。
元問題を使ったのか、条件を変えた類題なのかを区別し、必ず既存の問題ID・論点IDに関連付ける。新しい設問の厳密なIDが必要な場合に限り新規採番し、既存IDを再利用して別問題を同一問題として扱わない。
ユーザーが回答したら即時に採点し、その実際の回答・採点根拠・L1～L4評価・次回対応を attempts に追記する。質問文だけを提示した未回答は正解扱いしない。
1問正答しただけで習得済みにしない。重要論点はL4と別日・条件違いの類題確認まで必要。
questions と topics の最新情報を更新するときは元の問題ID・論点ID・既存履歴を維持する。
更新は GitHub の最新SHAを指定し、成功後に再取得して件数と対象演習イベントの存在を確認する。SHA競合なら最新内容を再取得して当該イベントが未登録か確認して再適用する。上書きしない。
演習イベントIDを重複させない。二重保存を避ける。保存できなかったら未保存と伝える。
余計なExcel、CSV、差分台帳、JSONコピーを作らない。ログは正本内の attempts の追記を基本とする。
音声で解ける実試験相当の問題を1問ずつ出す。略語の初出には正式英語を添える。
```

## 保存・更新フロー

1. GitHubで `master.json` を取得し、**blob SHA** を記録する。
2. 回答が確定したら、元のレコードを消さずに `attempts` へ追記し、必要に応じて `questions` と `topics` を更新する。
3. 取得時のSHAを使って同じファイルを更新する。競合したら最新を再取得して必要な差分だけを再適用する。
4. 更新成功後、ファイルを再読込し、演習イベントIDと対応する状態更新を確認する。
5. 「保存済み」と伝えるのは、GitHubへの更新と読み直しを確認できた場合だけにする。

ChatGPTの連携が自動で別チャットに状態を引き継ぐわけではありません。**各チャットでGitHubの正本を再取得する**ことが必要です。

## ダッシュボード

`index.html` は読み取り専用です。GitHub Pages のサイトとして公開したい場合、GitHub リポジトリの Settings → Pages で main / (root) からのデプロイを設定します。GitHub Pagesの公開範囲には注意してください。

ローカルで直接 `index.html` を開くだけでは、ブラウザーの制限で `master.json` を読み込めない場合があります。その場合はHTTPサーバー経由で開いてください。
